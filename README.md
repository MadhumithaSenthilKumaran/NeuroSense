# NeuroSense

## Cognitive task terminology and scoring

The cognitive module includes two distinct visual performance tasks:

- **Pair-Up visual memory task:** participants match hidden card pairs. The stored task measurements are completion time, matching attempts, correct matches, incorrect attempts, accuracy, a prototype time score, and a 0-100 Pair-Up Performance Score calculated as `(0.60 * accuracy) + (0.40 * time score)`.
- **1-25 number-order task:** numbers are placed once in a Fisher-Yates-shuffled 5x5 grid for each session. The participant selects them in order. Completion timing begins at Start and ends on 25; incorrect clicks are retained as errors and do not advance the sequence. The provisional task score is the time-band score from 0-10 minus 0.5 points per error, clamped to 0-10.

These are cognitive task performance scores for the NeuroSense multimodal feature set. The thresholds are provisional research bands, not validated clinical norms, Alzheimer's scores, or diagnostic cut-offs. Raw timings, errors, grid layout, and per-click intervals are retained so future age- and education-adjusted normative models can replace the prototype scoring without changing the task data.
